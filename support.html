SmartScan Pro Support

SmartScan Pro is a local-first barcode, inventory, tool tracking, and point-of-sale application. Most operational data is stored on the device where the app is installed.

Common help

  • Camera will not open: confirm camera permission is enabled for SmartScan Pro in Android Settings.
  • A code will not scan: improve lighting, hold the code steady, or use manual code entry.
  • Inventory looks missing: make sure you are using the same device/app installation. Local app data does not automatically sync between devices.
  • Before reinstalling or clearing app data: export a JSON backup if you need to preserve local records.
  • Product details are unavailable: public product lookup depends on Open Food Facts and may not contain every barcode.

Report a problem

For technical support, bug reports, or feature requests, use the SmartScan Pro repository issue tracker. Do not include passwords, card numbers, private customer information, or other sensitive data in a public report.
